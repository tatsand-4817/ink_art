# インクアート

水面に落としたインクが広がる模様を、WebGL2 の流体シミュレーションでリアルタイムに再現するアート制作アプリ。

要件定義は [`docs/requirements.md`](./docs/requirements.md)。

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 型チェック + 本番ビルド
```

## 現在の実装状況

| # | 機能 | 状態 |
|---|---|---|

| F-2 | インク投下操作(タップ/ドラッグ) | 実装済み |

## 設計上の判断

### 混色は「吸光度の加算」で行う(F-5)

要件定義では染料場を RGB 3 チャンネルで持ち、加算/ブレンドで混色させるとある。
ただし RGB を素朴に加算すると**加法混色**になり、青 + 黄 が白っぽく濁ってしまう。
実際のインクは光を吸収する減法混色なので、そのままでは「本物志向」から外れる。

そこで染料場には色そのものではなく **Beer–Lambert の吸光度** を蓄える。

- 投下時: インク色 `c` を `A = -log(linear(c))` に変換して染料場へ**加算**
- 描画時: `表示色 = 台紙の色 * exp(-A)`

吸光度が加算されるということは透過率が乗算されるということなので、
重なった部分は自動的に減法混色になる。青 + 黄 は緑になり、色を重ねるほど暗くなる。
チャンネル数は要件どおり 3 のままで、台紙の色も要件どおり背景として合成される。

副次的な利点として、`inkStrength = 1`(原液)のときインクの芯の色が
スウォッチの色とほぼ一致する。検証時の実測値:

| インク | スウォッチ | 芯の実測 |
|---|---|---|
| 墨 | `#1a1a1a` | `#191a1a` |
| 藍 | `#1f3f6e` | `#204275` |
| 山吹 | `#e8b22c` | `#edbb2f` |

山吹と藍を重ねた境界は `#2d3e20`(暗い緑)になり、減法混色が効いていることを確認済み。

**既知の制約**: このモデルは「光を吸収する染料」を表す。白や蛍光色のような
台紙より明るいインクは吸光度が負になり表現できない。
彩さんのモノクロ系プリセットに白インクを入れる場合は、
不透明顔料の被覆率を持つチャンネルを別途足す必要がある(要相談)。

### 一筆の濃さは移動距離で決める(F-2)

ドラッグ中はポインタイベントごとにインクを落とすが、その量をイベント数に比例させると
120Hz 端末で同じ操作をしただけでインクが倍載り、真っ黒に潰れる。
半径 2 つ分だけ動けば一滴と同じ濃さになるよう、移動距離で正規化している。

### タップ時に外向きの流れを作る

静止したタップは速度が 0 なので、そのままだとインクがその場で丸く滲むだけになる。
着水点の周囲に 8 方向の外向きの流れを一瞬だけ加えて、水面を押しのける挙動を出している
(`config.dropImpulse`)。

### 渦(渦度閉じ込め)

Stable Fluids は数値粘性で小さな渦が潰れる。カールを求めて渦を押し戻すパスを
入れており、「渦を巻く」挙動はほぼこれが担っている。`config.curl` で調整。
上げすぎると発散するので注意。

### フォーマット選定

`EXT_color_buffer_float` / `EXT_color_buffer_half_float` を有効化した上で、
実際に FBO を作って `checkFramebufferStatus` で**実測**して決めている。
拡張の有無だけを見ると嘘をつく実装があるため。
half float を優先(iOS Safari 向け、かつ WebGL2 コアで線形補間可)、
駄目なら float、線形補間が使えない場合はシェーダ側の手動補間に切り替わる。

シミュレーション解像度と表示解像度は分離済み(`simResolution` / `dyeResolution`)。
`devicePixelRatio` は `maxPixelRatio`(既定 2)で頭打ちにしている。

## チューニング

すべて `src/fluid/config.ts`。開発ビルドでは `window.__inkSim` からも触れる。

```js
__inkSim.updateConfig({ curl: 20, dyeDiffusion: 0.02 });
__inkSim.simulationSize  // 実際のシミュレーション解像度
__inkSim.precision       // 'half-float' | 'float'
__inkSim.samplePixel(0.5, 0.5)  // 表示色を 1 ピクセル読む(混色の確認用)
```

減衰率の半減期はおよそ `ln2 / 係数` 秒。`densityDissipation: 0.003` で約 4 分。
